# 10 - Web Protocols (HTTP, WebSockets, SMTP)

This module covers the core protocols used in modern web development to communicate over the internet. Understanding these protocols deeply is essential for system design and advanced backend engineering.

## Contents

1. [HTTP Deep Dive](./01_HTTP_DeepDive.md): Understand the Request/Response cycle, HTTP Methods, and Status Codes.
2. [WebSocket Mastery](./02_WebSocket_Mastery.md): **(Highly Recommended)** A complete guide to bidirectional, real-time communication. Explains why we need WebSockets, how the handshake works, and provides code examples using both `ws` and `socket.io`.
3. [SMTP & Email Delivery](./03_SMTP_Email.md): Learn how the Simple Mail Transfer Protocol works and how to programmatically send emails in Node.js using `nodemailer`.
